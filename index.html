About iOSS

Software should be open.

iOSS (iPhone Open Source Store) is an independent project dedicated to making open source software more accessible on Apple platforms.

Inspired by the philosophy of projects like F-Droid, our goal is to create an ecosystem where users can discover, explore and install open source applications for iPhone and iPad.

We believe software should be transparent, accessible and built with the community.
